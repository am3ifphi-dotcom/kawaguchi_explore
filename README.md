# 川口市立高等学校 3D探検 🏫

川口市の公開資料 **「新市立高等学校実施設計について」(全9頁)** と **広報かわぐち 2015年9月号(P02)** を
精読し、第1校地(埼玉県川口市上青木3-1-40)を **Three.js で3D再現した探検サイト** です。

## できること

- **🛰 俯瞰オルビット** — キャンパス全体を回転・ズーム。建物/スポットをクリックで解説カード。
- **🚶 徒歩モード** — WASD+マウスでキャンパス内を歩く(FPS操作)。
- **🎬 ガイドツアー** — 実施設計イメージ図の視点など9ステーションを自動飛行。
- **階タブ** — 校舎棟 B1〜5階 / アリーナS・N棟 1〜2階の全室間取りを、
  平面図ベースのカラー3Dブロック + 2Dカラー平面図で探検。
- **ガイド17スポット** — 膜屋根・ラーニングストリート・大アリーナ(観客席480)・人工芝グラウンド・
  竪川・都市の門/伝統の門・防災備蓄倉庫 ほか。
- **概要/沿革/面積表** — 敷地49,620.73㎡・延床31,631.68㎡・RC/S・地下1階地上5階・高さ21.89m 等を収録。

## 再現の根拠(資料頁)

| 資料 | 反映内容 |
| --- | --- |
| 配置図 03 | 各棟・広場・門・駐輪1,510台・竪川の位置関係 |
| 平面図 04–07 | B1〜5F の教室/実験室/コモンズ/食堂/アリーナ間取り |
| 立面・断面 08–09 | 軒高18.486m・高さ21.886m・階高3.6m・膜屋根・南面バルコニー |
| 設計概要 02 | 面積表・敷地条件・工程 |

## 開発

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ に静的ビルド
```

## Vercel デプロイ(GitHub 連携)

1. このリポジトリを GitHub へプッシュ済み(ブランチ `arena/01a0e2f4-kawaguchi-explore`)。
2. [vercel.com](https://vercel.com) → **Add New… → Project** → リポジトリを Import。
3. Framework Preset は **Vite** が自動検出されます(`vercel.json` 同梱: build=`npm run build`, output=`dist`)。
4. **Deploy** — 以降は main への push で自動デプロイ。

元のPDFは `public/source/` 配下からサイト内リンクでも閲覧できます。
