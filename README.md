# 川口市立高等学校 キャンパス探検 🏫🗺️

埼玉県川口市の公開資料を精読して作成した、**川口市立高等学校(2018年4月開校・市立3校統合)** のキャンパスを詳細に探検できる静的ウェブサイトです。

- 出典1: 「川口市新市立高等学校 実施設計」資料(`27901siryou.pdf`・9ページ) — イメージ図 / 設計概要 / 配置図 / 各階平面図 / 立面図 / 断面図
- 出典2: 広報かわぐち 2015年9月号「新市立高等学校の施設計画」(`P02.pdf`・1ページ)

## 🚀 GitHub → Vercel へのデプロイ方法

本リポジトリは**ビルド不要の純静的サイト**です。Vercelが自動検出できるため、設定はほぼゼロでデプロイできます。

### 方法A: Vercelダッシュボードから(推奨)

1. このリポジトリをGitHubにプッシュしておく
2. [vercel.com](https://vercel.com) にログイン → **Add New... → Project**
3. GitHubアカウントを連携し、このリポジトリを **Import**
4. 設定はそのまま(Framework Preset: **Other** / Build Command: なし / Output Directory: なし)で **Deploy**
5. 数十秒後に `https://<project-name>.vercel.app` で公開完了
6. 以降、`main` ブランチにpushするたびに自動で本番デプロイ、PRごとにプレビューURLが生成されます

### 方法B: Vercel CLIから

```bash
npm i -g vercel
cd kawaguchi_explore
vercel          # プレビューデプロイ
vercel --prod   # 本番デプロイ
```

### ローカルでの確認

```bash
cd kawaguchi_explore
python3 -m http.server 8000
# → http://localhost:8000
```

GitHub Pages にそのままホストすることも可能(ルートの `index.html` を参照)。

## 🧭 サイトの見どころ

| セクション | 内容 |
|---|---|
| 概要 | 3校統合のストーリー・学校データ・敷地案内図 |
| 配置図 | 実施設計「配置図」上の**29カ所のインタラクティブスポット**(施設カテゴリで絞り込み・解説表示) |
| フロア | 地下1階〜屋上の**階別床面積**(面積表)+ 平面図の拡大表示 |
| 施設 | ラーニングストリート・大アリーナ480席・人工芝グラウンド等のハイライト |
| データ | 面積表(棟×階)、建蔽率/容積率、駐車100台+バス4台・駐輪1,510台の内訳 |
| 歴史 | 2012年の基本計画〜SSH指定までのタイムラインと**3工区の工程図** |
| 図面 | 全10シートの**ディープズームビューア**(ホイール/ピンチ/ドラッグ) |

## 📁 構成

```
├── index.html            # 単一ページ(日本語)
├── assets/
│   ├── css/style.css
│   └── js/data.js        # 資料から抽出した全データ(座標・面積・工程など)
│   └── js/app.js         # UI実装(依存ライブラリなし)
├── img/
│   ├── sheets/           # 資料10シートの高解像度レンダリング(+thumbs/)
│   ├── plans/            # 階別平面図のクロップ
│   ├── campus/           # 配置図・敷地案内図・工程図
│   └── gallery/          # イメージ図・完成予想CG
├── 27901siryou.pdf       # 出典: 実施設計資料
├── P02.pdf               # 出典: 広報かわぐち 2015.9
├── build_assets.py       # PDF→画像アセットの再生成スクリプト(PyMuPDF)
└── vercel.json
```

## 🔄 アセットの再生成

PDFから図面画像を切り出し直したい場合は:

```bash
pip install pymupdf pillow
python3 build_assets.py
```
